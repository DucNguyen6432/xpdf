# Bin PDF Reader 🚀

A lightweight, minimalist desktop PDF reader built with **Electron**, **Node.js**, and **PDF.js**. Designed for speed, simplicity, and a clean user interface.

![App Icon](icon.ico)

## Features 🌟
- **Fast & Lightweight:** Built on Electron and modern web technologies.
- **Clean UI:** Minimalist interface focused purely on the reading experience.
- **Cross-Platform Ready:** Easily runnable and buildable on Windows, macOS, and Linux.

## Tech Stack 🛠️
- **Framework:** [Electron](https://www.electronjs.org/)
- **PDF Rendering:** [PDF.js](https://mozilla.github.io/pdf.js/)
- **Runtime:** [Node.js](https://nodejs.org/)
